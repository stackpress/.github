## Hi there 👋

AI is now taken over. And people vibing platforms is just wasting 
energy. Does AI really need to make another login page from the ground 
up? We might as well throw away abstraction, OOP and reusability out the 
window. Using AI to make Wordpress or Drupal is most optimal because 
things like auth, session, roles, permissions, security, content 
management has already been addressed. AI can just work on theming. 
Except modern apps aren't made with content management systems anymore.
In fact, 80% of AI generated code doesn't need to be generated if there
were libraries that covered all the common things needed to build an app.
